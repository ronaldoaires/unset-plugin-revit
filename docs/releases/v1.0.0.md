Primeira versão do novo plugin UnSet BIM para Revit 2025, 2026 e 2027.

- Biblioteca de famílias: busca, categorias, marcas, filtros e ordenação.
- Inserção da família direto no projeto, já pronta para posicionar.
- Favoritos e histórico de downloads, os mesmos do site.
- Entrada pelo navegador (funciona com contas do Google) ou com e-mail e senha.
- Atualizações automáticas pelo próprio plugin.
